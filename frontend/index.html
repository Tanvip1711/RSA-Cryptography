CONCEPT

How RSA works

01

Key generation

Two prime numbers are selected and multiplied to produce the RSA modulus. Mathematical relationships are then used to create the public and private keys.

02

Encryption

Each character is represented as a numeric value and transformed using the public key to produce ciphertext.

03

Decryption

The private key reverses the mathematical transformation and reconstructs the original message.
